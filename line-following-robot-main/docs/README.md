# Line Following Robot — ESP32

An autonomous robot that follows a black line on a white surface 
using IR sensors and a PID control algorithm.

## Hardware Components
- ESP32 development board
- IR sensors (line detection)
- L298N or similar motor driver
- 2x DC motors with wheels
- Robot chassis
- Power supply

## Software
- PID controller for smooth line tracking
- Sensor reading and calibration
- Motor speed control via PWM

## Project Structure
- `firmware/` — ESP32 source code (C++)
- `hardware/` — Circuit diagrams and schematics
- `docs/` — Documentation and build notes
- `tests/` — Test routines
